# Independent bracelet reconstructions

Four standalone GLB 2.0 models generated from original procedural geometry in `lib/bracelet-models.ts`. Standard PBR materials, mesh cords, knots, separate beads and vertex-colored brown/golden bands; no personal photograph textures, wrist or arm. The PNGs are deterministic browser renders of these GLBs.

These are conservative interpretations of the visible reference objects. Hidden shapes and knots are approximate, not photogrammetric scans. Their chronological order is black-detail, brown-strands, silver-cord, tiger-eye. Materials can be refined when the original reference files are supplied.
