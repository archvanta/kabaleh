The user-selected Mahboubeh Mehravar WOFF2 file is supplied locally and excluded from Git redistribution. Its accompanying ownership documents remain in `.private/font-documents/` and must never be copied into public assets. Place your authorized WOFF2 at `public/fonts/mahboubeh-mehravar.woff2` before building to use it throughout the site. With that optional file absent, the build uses the bundled OFL Vazirmatn fallback without fetching a missing font. Do not modify licensed font files or invent license identifiers.
