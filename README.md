# KABALEH — لابه لای آذر

نامه و دفتر خاطرات تعاملی فارسی برای تولد مشکات با پاکت مومی و نخ قرمز پیوسته

## وضعیت محتوا

درخواست جدید کاربر انتشار عمومی متن تاییدشده و عکس های ارسالی را مجاز کرده و جایگزین تصمیم قبلی برای پیش نمایش محلی شده است

- `content/approved-copy.json` متن پایه تاییدشده بدون بازنویسی ادبی
- `content/letter.json` محتوای اعتبارسنجی شده و ۲۴ بخش پس از پاکت با ترتیب مشخص
- `content/ui.json` برچسب های رابط
- `content/photo-manifest.json` فهرست و هش ۲۱ عکس اصلی در ۱۴ گروه
- `public/images/originals/` فایل های اصلی بدون تغییر بایت ها و بدون برش یا دستکاری

تبریک تولد ابتدا و نامه اصلی نزدیک پایان می آید
متن ها با خط جدید و بندهای جدا نمایش داده می شوند و نیم فاصله و ویرگول و نقطه ندارند
یادداشت ها در کاغذهای بازشدنی باقی مانده اند
عکس های گروهی یک روایت مشترک دارند و فایل کامل هر عکس از گالری قابل دیدن است
نوع و تصویر کادوی امسال در بخش مربوط به آن افشا نمی شود

## اجرا

Node.js 24 و npm 11 لازم است
هر تسک ابری از قبل محیط مستقلی دارد و از checkout موجود استفاده می کند
بدون درخواست صریح کاربر worktree تازه نسازید

```sh
npm ci --cache /workspace/.npm-cache --no-audit --no-fund
npm run dev
```

برای خروجی تولید

```sh
npm run build
npm start
```

خروجی `out/` کاملا استاتیک است و `npm start` آن را با سرور کوچک Node روی پورت ۳۰۰۰ ارائه می دهد
پورت با `PORT` قابل تغییر است
`GET /api/content/` هنگام build تولید می شود و مسیر ویرایش عمومی یا دیتابیس آنلاین وجود ندارد
تغییر محتوای JSON به build دوباره نیاز دارد و به بازسازی UI نیاز ندارد

## انتشار GitHub Pages

workflow با push روی `main` و با اجرای دستی فعال می شود
GitHub Pages باید از GitHub Actions استفاده کند
workflow مسیر پایه را از تنظیمات Pages می گیرد
برای بررسی زیرمسیر پروژه

```sh
NEXT_PUBLIC_BASE_PATH=/kabaleh npm run build
NEXT_PUBLIC_BASE_PATH=/kabaleh PORT=3002 npm start
```

فونت منتخب کاربر **Mahboubeh Mehravar** است و روی کل رابط و نوشته های فارسی و لاتین اعمال می شود
فونت وب اصلی بدون تغییر در شاخه دارایی `site-assets` نگهداری می شود و اسکریپت `scripts/install-deployment-font.mjs` آن را از همان مخزن می گیرد و SHA-256 آن را پیش از build بررسی می کند
این روش به مجوز مدیریت GitHub Secrets نیاز ندارد
فایل فونت در شاخه کد برنامه نادیده گرفته می شود و در خروجی منتشرشده سایت وجود دارد
مدارک مجوز دارای اطلاعات مالک فقط در `.private/font-documents/` می مانند و وارد مخزن یا خروجی نمی شوند
برای توسعه محلی فونت اصلی در `public/fonts/mahboubeh-mehravar.woff2` قرار می گیرد
در نبود آن اجرای محلی از Vazirmatn با مجوز OFL استفاده می کند ولی workflow انتشار وجود فونت اصلی را الزام می کند

## بررسی

```sh
npm run build
npm run typecheck
npm test
npm run test:e2e
```

تست های محتوا ترتیب ۲۴ بخش و حفظ کل متن تاییدشده و هش تمام ۲۱ عکس و قواعد نوشتاری و مخفی ماندن کادوی امسال را بررسی می کنند
تست مرورگر خروجی تولید را روی پورت ۳۱۰۰ اجرا می کند و شامل دسکتاپ و شبیه سازی موبایل و لمس و عرض ۳۲۰ و RTL و کاهش حرکت و پاکت و یادداشت و گالری و فایل عکس اصلی و مدل سه بعدی و حالت بدون WebGL است
Chromium از `/usr/bin/chromium` استفاده می شود و مسیر دیگر با `PLAYWRIGHT_CHROMIUM_EXECUTABLE` قابل تنظیم است
رندر نرم افزاری سه بعدی ممکن است چند دقیقه زمان ببرد
این بررسی جای تست دستگاه واقعی iOS را نمی گیرد

## مدل ها و موارد نیازمند منبع

چهار مدل GLB مستقل و ترتیب قدیمی به جدید حفظ شده اند
آن ها بازسازی هندسی بر اساس نمای مرجع هستند و دقت قسمت های پنهان قطعی نیست
مدل ها را با `npm run models:export` می توان از `lib/bracelet-models.ts` دوباره تولید کرد
نمایشگر هنگام درخواست کاربر بارگذاری و پس از بستن آزاد می شود

انتساب عکس گروه `05_university_sketch` به روایت اسکیس طبق منبع نیازمند تایید است و فقط در داده داخلی علامت دارد
فایل های اصلی نمای دستبندها و عکس نزدیک پین که در چت دیده شدند هنوز به صورت فایل در محیط نیستند
متن پین و پاکت یادداشت آن نمایش داده می شود ولی مدل دقیق دارای بافت پین ادعا نمی شود
عکس واقعی دست نوشته و عکس پاکت دست ساز بدون تغییر از گروه چهاردهم نمایش داده می شوند
مسیر ویندوزی کاربر از محیط ابری قابل دسترسی نیست و عکس های بیشتر باید پیوست شوند
فایل های `.private` و مدارک مالکیت و اطلاعات حساس نامرتبط هرگز منتشر نمی شوند
