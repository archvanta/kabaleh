# MESHKAT · نامه‌ای برای مشکات

یک نامهٔ تعاملی فارسی با پاکت مومی، دفتر خاطرات اسکرولی، نخ قرمز پیوسته و یادگاری‌های سه‌بعدی. نوشته‌های احساسی نهایی عمداً اضافه نشده‌اند؛ متن‌های نمونه در فایل محتوا مشخص‌اند.

## اجرا

Node.js 24 و npm 11. در محیط ابری از همین checkout استفاده کنید؛ هر تسک از قبل محیط مستقلی دارد و نیازی به worktree نیست.

```sh
npm ci --cache /workspace/.npm-cache --no-audit --no-fund
npm run dev
```

دستور دوم توسعه را روی پورت ۳۰۰۰ اجرا می‌کند. برای خروجی تولید:

```sh
npm run build
npm start
```

`out/` یک خروجی استاتیک است. `npm start` آن را با سرور کوچک Node ارائه می‌دهد؛ Next.js در این معماری سرور دائمی لازم ندارد. پورت با `PORT` قابل تغییر است. وضعیت واقعی با درخواست صفحه و `/api/content/` بررسی شود، نه صرفاً باز بودن پورت.

## محتوا

`content/letter.json` نسخهٔ نمایشی عمومی است. `lib/content.ts` ساختار آن را با Zod اعتبارسنجی می‌کند. فیلد `sections` ترتیب و نمایش بخش‌ها را تعیین می‌کند. عکس‌ها نسبت طبیعی خود را حفظ می‌کنند؛ آلبوم بزرگ‌نمایی، صفحه‌کلید و پیوند به فایل تصویر دارد. تاریخ‌های نامعلوم خالی می‌مانند.

`GET /api/content/` هنگام build تولید می‌شود. این یک خروجی خواندنی از فایل محتواست، نه دیتابیس یا CMS آنلاین. مسیر نوشتن عمومی یا پنل ویرایش بدون احراز هویت وجود ندارد. تغییر محتوای JSON نیازمند build مجدد است؛ تغییر UI لازم نیست.

## عکس‌های شخصی؛ فقط پیش‌نمایش محلی

طبق انتخاب کاربر، اصل عکس‌ها و اطلاعات شخصی نباید commit، push یا منتشر شوند:

- `.private/originals/` اصل فایل‌ها، بدون تغییر بایت‌ها.
- `.private/manifest.json` اندازه و SHA-256 فایل‌ها.
- `.private/letter.json` نسخهٔ محتوای شخصی.
- `.private/source-context.txt` متن منبع؛ زمینهٔ خاطرات است، نه متن نهایی.
- `.private/out/` خروجی شخصی که از `out/` عمومی جداست.

```sh
npm run preview:personal
```

این دستور فقط در صورت وجود فایل‌های بالا کار می‌کند. خروجی شخصی را می‌سازد و آن را روی loopback پورت ۳۰۰۰ اجرا می‌کند. برای اجرای هم‌زمان با توسعه، `PORT=3001 npm run preview:personal` استفاده کنید. سرور این حالت را فقط به `127.0.0.1` متصل می‌کند. آن را تونل نکنید یا به پیش‌نمایش عمومی تبدیل نکنید. عکس‌ها بیرون از `public/` هستند و سرور عادی آن مسیرها را ارائه نمی‌دهد.

حالت عادی به دادهٔ شخصی مراجعه نمی‌کند. هیچ دستور build یا workflow عمومی نباید `MESHKAT_PERSONAL_PREVIEW=1` تنظیم کند. فایل‌های `.private` در Git نادیده گرفته می‌شوند و فقط در همین محیط نگه داشته شده‌اند.

## فونت انتخابی

فونت فعال کاربر **Mahboubeh Mehravar** است و کل رابط، از جمله نوشته‌های لاتین و کنترل‌ها، از آن استفاده می‌کند. فایل WOFF2 اصلی بدون دستکاری در `public/fonts/mahboubeh-mehravar.woff2` قرار می‌گیرد. این فایل دارای مجوز اختصاصی است و در Git بازتوزیع نمی‌شود. اسناد همراه فونت اطلاعات مالک دارند و فقط در `.private/font-documents/` نگهداری می‌شوند.

در clone تازه باید فایل مجاز خودتان را در مسیر بالا قرار دهید و build بگیرید. در نبود آن، سایت بدون درخواست فایل گمشده از Vazirmatn با مجوز OFL استفاده می‌کند. برای انتشار با فونت انتخابی، فونت مجاز باید در محیط build استقرار موجود باشد. فونت قبلی Fedra کنار گذاشته شده است.

## یادگاری‌های سه‌بعدی

چهار GLB هندسی مستقل در `public/models/` وجود دارد، با این ترتیب ثابت:

1. بند مشکی و قطعهٔ فلزی کوچک
2. بند قهوه‌ای چندرشته‌ای
3. بند مشکی و قطعهٔ نقره‌ای کشیده
4. مهره‌های قهوه‌ای و طلایی

مدل‌ها بازسازی مستقل بر اساس نماهای مرجع هستند، نه اسکن دقیق. قسمت‌های پنهان تقریبی‌اند. هندسه، مواد PBR، گره‌ها و رنگ‌های سطح مهره‌ها در مدل‌اند؛ عکس تختِ چرخان نیستند. برای تغییر مدل‌ها `lib/bracelet-models.ts` را ویرایش و `npm run models:export` اجرا کنید. تصاویر ثابت از رندر همین GLBها گرفته شده‌اند. نمایشگر فقط هنگام درخواست کاربر بارگذاری می‌شود و با بستن آن منابع WebGL آزاد می‌شوند. صفحهٔ اصلی canvas دائمی ندارد. ماوس، لمس، کلیدهای جهت، بزرگ‌نمایی و حالت بدون WebGL پشتیبانی می‌شوند.

بخش پین و ورودی نمایشگر آن پیاده‌سازی شده است، اما بازسازی دقیق پین و بافت اصلی آن هنوز به فایل اصلی عکس‌های ارسال‌شده در چت نیاز دارد. شیء جایگزین یا تصویر ساختگی به‌عنوان پین اصلی ارائه نمی‌شود. جای عکس مرجع و GLB در `bagPin` آماده است.

## بررسی

```sh
npm run build
npm run typecheck
npm test
npm run test:e2e
```

تست مرورگر از Chromium نصب‌شده در `/usr/bin/chromium` استفاده می‌کند. برای محل دیگر، `PLAYWRIGHT_CHROMIUM_EXECUTABLE` تنظیم شود. تست‌ها خروجی تولید را روی پورت ۳۱۰۰ شروع می‌کنند. در CI می‌توان Chromium را با Playwright نصب کرد و مسیرش را به متغیر بالا داد. پوشش شامل پاکت و بازپخش، بخش‌های دفتر، نخ متصل، یادداشت‌ها، آلبوم و برگشت فوکوس، بلفی، ترتیب و چرخش چهار مدل، نبود WebGL، کاهش حرکت، عرض‌های ۳۲۰ و ۳۹۰ و ۱۴۴۰ پیکسل، API فقط‌خواندنی و عدم ارائهٔ عکس خصوصی در سرور عمومی است. تست موبایل شبیه‌سازی Chromium است؛ جای تست دستگاه واقعی iOS را نمی‌گیرد.

## استقرار

این معماری روی GitHub Pages یا هر میزبان استاتیک قابل اجراست. بک‌اند Node دائمی روی Pages ادعا نمی‌شود. برای مسیر پروژهٔ Pages:

```sh
NEXT_PUBLIC_BASE_PATH=/kabaleh npm run build
NEXT_PUBLIC_BASE_PATH=/kabaleh npm start
```

workflow دستی `.github/workflows/pages.yml` فقط نسخهٔ نمایشی عمومی را می‌سازد. ابتدا Pages باید در تنظیمات repository روی GitHub Actions فعال باشد. اجرای دستی انتشار باید پس از فراهم‌بودن مجوزها و فایل فونت مجاز انجام شود. وجود workflow یا خروجی محلی به معنای انجام استقرار یا وجود URL تأییدشده نیست.

## محدودیت‌های محتوایی

دو وب‌سایت مرجع در محیط اولیه با خطای سیاست شبکه مسدود بودند؛ طراحی بر اساس توضیحات کاربر و تصاویر مرجع قابل‌مشاهده انجام شد. هنر دکوراتیو اصلی و تصاویر نمایشی از عکس‌های شخصی جدا هستند. روایت اسکیس دانشگاه در بستهٔ منبع به تطبیق نیاز دارد؛ اطلاعات ناشناخته یا تاریخ ساختگی اضافه نشده است. مسیر `C:\Users\...` از محیط ابری قابل دسترسی نیست؛ تصاویر بیشتر باید به‌صورت فایل پیوست شوند.
